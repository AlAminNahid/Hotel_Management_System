# 🏨 Hotel Management System  
*A Java & Swing-based desktop application*

## 📌 Project Overview
This project is a **Hotel Management System** built using **Java** and **Java Swing** for the user interface.  
Instead of a database, it uses **text files** for data storage via `BufferedReader` and `BufferedWriter`.

The system helps hotel staff manage bookings, customers, rooms, and essential hotel operations in a simple desktop environment.

---

## 🛠️ Technologies Used
- **Java**
- **Java Swing (GUI)**
- **File Handling** using BufferedReader & BufferedWriter
- **Object-Oriented Programming**

---

## ✨ Features
- Add, update, and delete customer information  
- Book and manage rooms  
- View available and reserved rooms  
- Store all records in local text files  
- User-friendly graphical interface  
- Validations to avoid incorrect data entry
